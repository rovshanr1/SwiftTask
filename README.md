# SwiftTask - Task Management & Focus App

## Overview
SwiftTask is a comprehensive task management and focus application built with SwiftUI. It combines powerful task organization features with focus mode capabilities to help users stay productive and maintain concentration on their work.

## Features

### Task Management
- Create, edit, and delete tasks
- Categorize tasks with predefined categories (Work, Personal, Study, etc.)
- Set task priorities (Low, Medium, High, Urgent)
- Mark tasks as complete
- Task filtering and search functionality

### Focus Mode
- Customizable focus timer (25min, 45min, 1hr, 1.5hr, 2hr)
- Focus session tracking
- Visual progress display
- Focus history with graphical representation
- Daily focus statistics

### User Profile
- Customizable user profiles
- Profile picture support
- Personal information management

### Authentication
- Firebase Authentication integration
- Guest mode support
- Secure user data handling

## Technical Stack
- SwiftUI for UI development
- Core Data for local data persistence
- Firebase for authentication
- MVVM architecture pattern
- Combine framework for reactive programming

## Requirements
- iOS 15.0+
- Xcode 13.0+
- Swift 5.5+

## Installation
1. Clone the repository
```bash
git clone https://github.com/rovshanr1/SwiftTask.git
```

2. Open SwiftTask.xcodeproj in Xcode

3. Install dependencies (if using CocoaPods or SPM)

4. Build and run the project

## Architecture
The project follows the MVVM (Model-View-ViewModel) architecture pattern:
- Models: Core Data entities and data models
- Views: SwiftUI views for UI
- ViewModels: Business logic and data management
